# Menu Fold Formats — Reference

## Key Principles

1. Each photo shows one SIDE of the menu. For folded menus (bifold, trifold, quad), the menu is opened flat and photographed — one photo shows all panels on that side. For booklets, each photo is a separate spread or page.
2. A "panel" = one physical page of the folded menu.
3. Panels within the same fold are roughly EQUAL WIDTH (allow ±15-20% tolerance for skewed photos).
4. A panel can have 1, 2, or 3 content columns — the number of columns per panel is independent of fold type.
5. Every item-column (with prices) has the SAME WIDTH across the entire menu — front and back, all panels.
6. Content panels almost always have the SAME number of columns as each other.
7. Cover panels are always exactly 1 panel. They contain the venue name/logo. They are never folded in the middle. Their position depends on the folding direction — can be any panel.
8. The back side sometimes has a back-cover or info panel (address, opening hours, phone).

## Format Definitions

### A5 portrait / A4 portrait
- **Total panels**: 2 (front + back)
- **Per photo**: 1 panel
- **Common columns**: 1-2 per panel, sometimes 3
- **Cover**: rarely has a separate cover — both sides are usually content
- **Can be 2 photos**: yes, front + back

### A4 landscape
- **Total panels**: 2 (front + back)
- **Per photo**: 1 panel
- **Common columns**: 2-3 per panel
- **Cover**: rarely has a separate cover

### bifold
- **Total panels**: 4 (2 per side)
- **Per photo**: 2 panels
- **Common columns**: 1-2 per panel (so 2-4 columns per photo)
- **Cover**: usually 1 cover panel on one side

### trifold / zfold
- **Total panels**: 6 (3 per side)
- **Per photo**: 3 panels
- **Common columns**: ALWAYS 1 column per panel (so 3 columns per photo). Trifold panels are too narrow for multiple columns.
- **Cover**: usually 1 cover panel

### four-panel (quad-fold)
- **Total panels**: 8 (4 per side)
- **Per photo**: 4 panels
- **Common columns**: 1-2 per panel (so 4-8 columns per photo)
- **Cover**: usually 1 cover panel

### booklet (a4-booklet / a5-booklet)
- **Total panels**: 8+ (multiple pages)
- **Per photo**: 1-2 panels
- **Photos**: 3+
- **Common columns**: 1-2 per panel

## Inference Reasoning — Follow These Steps

### Step 1: Photo count
- 1 photo → flat (A5/A4), single side
- 2 photos → could be flat OR folded — need more analysis (continue to step 2)
- 3+ photos → booklet

### Step 2: Find the standard column width (using BOTH photos)
Every item-column has the same width across the entire menu. Collect all content column widths from both photos. They should cluster around one value — that is the standard column width.

### Step 3: Quick match — equal columns per photo
If both photos have the SAME number of columns, and the column widths are roughly equal (each ~1/N of the photo width), the fold type can be determined directly:
- Both photos have 1 column each (~100% width) → flat (A5/A4), 1 panel per side
- Both photos have 2 columns each (~50% width) → bifold, 1 col/panel, 2 panels per side
- Both photos have 3 columns each (~33% width) → trifold, 1 col/panel, 3 panels per side
- Both photos have 4 columns each (~25% width) → quad-fold, 1 col/panel, 4 panels per side

This also applies when one photo has a cover column: e.g. both photos have 3 columns, one is cover → still trifold (cover takes 1 panel, 2 content panels on that side, 3 content panels on other side = 6 panels total).

If both photos have different column counts, continue to step 4.

### Step 4: Determine columns-per-panel (when photos differ)
A bifold with 2 columns per page has 4 columns per photo. Key rule: if a bifold has 2 columns per page on one content page, ALL content pages must have 2 columns. So:
- If one photo has 4 content columns and the other has 2 content columns + cover → the 4-column photo has 2 panels (2 cols each), the other has 1 content panel (2 cols) + 1 cover = 2 panels → bifold (4 total)
- If one photo has 4 content columns and the other has 4 content columns → bifold with 2 cols/panel (4 panels per side = 8 total? No — bifold = 2 panels per side). So 4 columns with 2 cols/panel = 2 panels per side → bifold.

### Step 5: Count panels per photo
For each photo:
- Count cover/info zones — each is 1 panel
- Group remaining content columns into panels (using columns-per-panel)
- Total panels for this photo = content panels + cover panels

### Step 6: Total panels across both photos → fold type
- 2 total → flat (A5/A4)
- 4 total → bifold
- 6 total → trifold
- 8 total → four-panel (quad-fold)

### Step 7: Verify
- All panels (including cover) should be roughly the same width (±15-20% tolerance)
- A bifold with 2 cols/panel: each panel = ~50% width, so column width = ~25%. If column width = ~33%, it's NOT a bifold — it's a trifold.
- The number of panels MUST match one of the fold types. If your count gives 5 or 7, your grouping is wrong.

IMPORTANT: Always consider BOTH photos together. You cannot reliably infer the fold type from one photo alone.

## Common Pitfalls

- 2 photos does NOT automatically mean folded — A5/A4 flat menus also have front + back
- A bifold with 2 columns per page has 4 content columns per photo → 4 columns ≠ 4 panels
- An A4 landscape with 3 columns has 3 columns but only 1 panel → 3 columns ≠ 3 panels
- Phone numbers and postal codes on cover panels look like prices → they're not
- The fold type is determined by panel count, NOT by column count
- A trifold NEVER has 2 columns per panel — trifold panels are too narrow. If you see 2 columns per panel, it's a bifold, not a trifold.
- A cover panel is ALWAYS its own page/panel. It is NEVER grouped with a content column on the same panel. If your grouping puts a cover and a content column on the same panel, the grouping is wrong — increase the panel count.
- If both photos have 4 columns each, and at least one column is a cover → it MUST be a quad-fold (8 panels, 1 column per panel). A bifold would require 2 columns per panel, but a cover can't share a panel with content, making bifold impossible.
- If both photos have 3 columns each (~33% width) → it's a trifold, NOT a bifold. A bifold with 1 col/panel would give 6 panels (impossible for bifold). A bifold with 2 cols/panel would need 4 columns per photo, not 3. So 3 equal columns per photo = trifold.
- 6 panels = trifold. NEVER write "bifold" when you count 6 panels.
- Don't infer from one photo alone — always use both sides together
